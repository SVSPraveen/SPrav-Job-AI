🚀 Quick Start Guide

From clean download to automated career discovery in under 60 seconds. Zero command-line setup or complex installations required.

1

Download & Extract Portable Package

Download SPrav_Job_AI_Pro_v2.4.5_Portable.zip from GitHub or Google Drive. Extract anywhere on your Windows PC (e.g. C:\SPravJobAI\). No installer, admin privileges, or registry modifications needed.

2

Double-Click Launch

Double-click SPravJobAI.exe or Start SPrav AI.vbs. The high-performance local FastAPI backend initializes and automatically opens your browser to http://127.0.0.1:8000/.

http://127.0.0.1:8000/
3

Drop Your Master Resume PDF

Head to Knowledge Base and upload your PDF resume. The 4-engine layout parser (pdfplumber + pypdfium2) indexes your work experiences, verified skills, and quantifiable impact bullets into your local ground-truth store.

4

Select Free Cloud or Local Offline AI

In Settings, pick your preferred AI inference mode:
• Free Cloud Key: Google Gemini 2.0 Flash or Groq LPU (0% GPU/RAM cost).
• 100% Air-Gapped Local: Local Ollama running Qwen 2.5 Coder (zero internet calls).

ollama run qwen2.5-coder:7b
5

Calibrate Application Scope

Select target role categories (AI/ML, Python Backend, Full-Stack, etc.) and location preferences with 1-click Quick-Add palettes.

6

Click "Start Loop" & Review

Click Start Loop on your Command Center. SPrav scans 28,700+ career boards, calculates cosine similarity against your master resume, and queues verified matches under Action Required for your 1-click dispatch approval.

⚡ REST API Reference

All local endpoints exposed by the FastAPI server on http://127.0.0.1:8000/api.

Endpoint Method Description
/api/jobs GET Paginated job catalog endpoint with source filtering, status filtering, and sorting parameters.
/api/jobs/manual GET Fetches active Action Required queue (Best Matches, Solid Near-Miss, Reviewable) with in-memory deduplication.
/api/metrics GET Returns live discovery counters, queue depths, total applications sent, and screening yields.
/api/system/readiness GET Returns setup guard status (kb_ready, scope_ready, ai_configured).
/api/loop/status GET Returns real-time daemon state (e.g. "Standby", "Scanning ATS Boards...").
/api/loop/start POST Triggers continuous background discovery and scoring cycle.
/api/loop/stop POST Gracefully halts the background loop after current batch finishes.
/api/kb GET Returns candidate master ground-truth JSON profile and categorized skill arrays.
/api/scope GET / POST Retrieves or updates candidate target roles, location preferences, and exclusion lists.
/api/credentials GET / POST Manages encrypted local API keys (Gemini, Groq, GitHub PAT) with AES-GCM encryption.

🔄 5-Stage Operational Pipeline

The closed-loop lifecycle from real-time job board discovery to candidate 1-click dispatch.

📡

Stage 1 — Multi-Channel ATS Discovery

Scrapes 28,700+ verified career boards (Greenhouse, Lever, Ashby, Workday) and remote feeds. Extracts direct authentic company posting links with deterministic SHA-1 hashing.

🛡️

Stage 2 — Application Scope Gate

Instantly verifies role title matching, location taxonomy, and negative exclusions in <1ms. Filters out-of-scope roles without wasting AI inference.

🎯

Stage 3 — ATS Semantic Matching & Rubric Scoring

Calculates skill cosine similarity against candidate Master Resume graph. Triages into 🌟 Best Matches (≥65%), 💜 Solid Near-Miss (48-64%), or 📋 Reviewable.

⭐

Stage 4 — Guided 1-Click Dispatch Queue

Generates tailored cover notes, 3 STAR stories, and recruiter cold outreach pitch. Candidate reviews all materials and clicks "Open & Apply" to submit.

📋

Stage 5 — Telemetry & Conversion Analytics

Logs submitted applications with timestamps, computes screening yields, and tracks employer response latencies in local SQLite.

❓ Frequently Asked Questions

Common questions regarding installation, security, AI configuration, and daily operations.

Is SPrav™ Job AI completely free to use forever? ▼
Yes, 100% free freeware. There are zero subscriptions, paid tiers, or hidden credits. You can use free cloud AI tiers (Google Gemini 2.0 Flash / Groq) or run 100% offline with local Ollama on your own GPU.
Is my resume or personal data sent to external cloud servers? ▼
No. All personal data, master resumes, and application logs remain strictly on your local PC in %LOCALAPPDATA%\SPravJobAI. Zero data is transmitted to external telemetry servers.
Does the app blind-apply to hundreds of companies without my review? ▼
No. SPrav uses a human-in-the-loop Guided Dispatch model. It pre-scans, scores, and prepares tailored materials, but requires your 1-click review and approval before submitting. This protects your candidate reputation and prevents ATS bot disqualifications.
How do I run 100% offline with Local Ollama? ▼
Install Ollama from ollama.com and run ollama run qwen2.5-coder:7b in your terminal. SPrav auto-detects the running Ollama instance and executes all tailoring locally without making any external API calls.
