🚀 Quick Start Guide

From zero to autonomous job search in under 60 seconds — no Python, no command line, no dependencies required.

1

Download & Extract

Download SPrav_Job_AI_Pro_v2.4.5_Portable.zip from the GitHub Release page. Extract the ZIP to any folder on your Windows PC — e.g. C:\Apps\SPravJobAI\. No installer needed.

2

Launch SPravJobAI.exe

Double-click SPravJobAI.exe. The local server starts automatically and your default browser opens to http://127.0.0.1:8000/. The dashboard authenticates you automatically — no login required.

3

Upload Your Master Resume

Navigate to Knowledge Base and upload your master resume in PDF format. SPrav's 4-engine parser extracts your work history, projects, skills, certifications, and quantified metrics to form your personal ground truth for all AI scoring.

4

Configure Free Cloud AI or Local Ollama

SPrav supports 100% free operation using either: Free Cloud AI (get a free API key from Google AI Studio for Gemini 2.0 Flash, or Groq LPU Console) or 100% Local Air-Gapped AI — install Ollama and run ollama run qwen2.5-coder:7b. SPrav auto-detects Ollama and routes all inference locally on your GPU with zero internet calls.

5

Set Your Application Scope

Navigate to Application Scope to specify your target job roles (e.g. AI Engineer, Generative AI, Full Stack Developer) and preferred locations (e.g. Remote, India, Bengaluru, San Francisco) using the 1-click 800+ role typeahead and 246-country geo-taxonomy palettes.

6

Start the Autonomous Loop & Apply

Click Start Loop on the Command Center. SPrav continuously scans 28,700+ ATS feeds, scores matches against your resume, and populates Action Required. For each high-match job (ATS ≥ 65%), review the tailored cover note and STAR stories, then click Open & Apply to dispatch with 1 click.

🔧 Reference Manual

Exhaustive technical documentation covering all core engine subsystems and architectural components.

📡 Autonomous Ingestion Daemon

Continuous background scheduler monitoring 28,700+ 1st-party ATS feeds — Greenhouse, Lever, Ashby, Workday, SmartRecruiters. Runs silently with zero CPU idle usage via SQLite WAL queuing.

🎯 Hybrid ATS Matcher

Evaluates 26,062 jobs/second in-memory. Calculates cosine similarity over extracted skill vectors, rubric dimensions, and keyword density. Produces a 0–100% match score per job.

🧠 Knowledge Base Engine

Stores a 10-domain semantic skill graph with ground-truth PDF verification. Parses any resume worldwide via 4-engine cascading PDF extraction with zero hardcoding.

🛡️ Scope Enforcer

Sub-millisecond in-memory filter validating work mode, location, and target role eligibility before any job enters the scoring queue — preventing irrelevant application spam.

📈 Conversion Analytics

Real-time telemetry computing application yield, interview progression rates, response latency per employer, and ghost detection for non-responding ATS portals.

📧 Recruiter Outreach Engine

Scrapes technical hiring manager contacts via LinkedIn and company directories, then drafts personalized warm-path connection notes anchored to the specific job context.

✍️ Cover Note AI Generator

Generates concise, honest 3-paragraph cover notes anchored to your actual resume achievements — never hallucinates. Capped at 220 words to ensure recruiter readability.

🔒 Local Security Boundary

All candidate data stored exclusively in %LOCALAPPDATA%\SPravJobAI. Zero data transmitted to external servers. JWT tokens are local-only, never exfiltrated.

⚡ API Reference

All FastAPI endpoints exposed by the local backend at http://127.0.0.1:8000

Endpoint Method Description
/api/auto-login GET Returns a local JWT access token automatically. Zero credentials needed — all tokens are local-only and never transmitted.
/api/metrics GET Live job discovery counter, action required queue depth, applications sent, interviews, and rejection stats. Used to power the Command Center dashboard cards.
/api/loop/status GET Returns current loop telemetry state — active: bool and current state: string (e.g. "Scanning ATS Boards...").
/api/loop/start POST Starts the autonomous discovery and scoring daemon in the background if not already running.
/api/loop/stop POST Gracefully stops the discovery loop after the current scraping cycle completes.
/api/jobs GET Paginated job portal endpoint. Supports ?status=action_required, ?search=, ?page=, and ?limit= query parameters.
/api/jobs/{id}/tailor POST Triggers AI tailoring for a specific job — generates cover letter, rewrites resume bullets, builds STAR stories, and evaluates ATS match rubric.
/api/kb/upload POST Accepts a master resume PDF. Triggers the 4-engine extraction pipeline and rebuilds the candidate knowledge base and skill graph.
/api/scope GET Returns the current application scope configuration — target roles array, locations array, and remote/hybrid/on-site work mode filter.
/api/scope POST Updates the application scope. Triggers immediate re-evaluation of all existing jobs against the new scope criteria.
/api/system/readiness GET Returns system readiness status — kb_ready, scope_ready, ai_configured. Used to power the FTUX setup guard on the Command Center.
/api/history GET Application history log — all dispatched jobs with timestamps, employer info, tailored cover note, and application outcome status.

🔄 5-Stage Operational Workflow

How every job transitions from initial discovery across 28,700+ ATS feeds to a successfully dispatched, tailored application.

📡

Stage 1 — Autonomous Ingestion Daemon

Continuously scrapes 28,700+ verified tech company ATS boards (Greenhouse, Lever, Ashby, Workday), community job feeds (HN, WeWorkRemotely, Himalayas), and company career pages via Playwright Stealth browser.

↓
🛡️

Stage 2 — Scope Enforcer Gate

Each discovered job is instantly evaluated against your Application Scope — work mode (Remote/Hybrid/On-site), target locations (246-country geo-taxonomy), and 800+ standardized target role titles. Irrelevant jobs are filtered in <1ms without consuming AI quota.

↓
🎯

Stage 3 — Hybrid ATS Matcher & Rubric Scoring

In-scope jobs are scored via cosine similarity over extracted skill vectors against your Knowledge Base graph. A full 8-dimension rubric (Technical Depth, Culture Fit, Impact Quantification, etc.) is evaluated using your chosen AI provider, producing a 0–100% match score.

↓
⭐

Stage 4 — Guided 1-Click Dispatch (Action Required)

High-fidelity matches (ATS ≥ 65%) surface in the Action Required queue. For each job, SPrav generates: a tailored 220-word cover note, 3 STAR behavioral interview stories, rewritten bullet points in Google XYZ format, and a contact outreach draft. You review, approve with 1 click, and the job opens for immediate application.

↓
📋

Stage 5 — Application History & Conversion Analytics

Every dispatched application is archived in local SQLite with full metadata — tailored content, timestamp, employer contacts, and outcome status. Conversion analytics compute yield rates, response latency per company, ghost detection, and interview progression tracking.

❓ Frequently Asked Questions

The most common questions from candidates downloading and using SPrav™ Job AI for the first time.

Is SPrav™ Job AI truly free? ▼
Yes — 100% free freeware. There are no subscriptions, credits, paywalls, or hidden fees of any kind. The AI scoring uses free-tier API keys from Google AI Studio (Gemini 2.0 Flash) or Groq, both of which provide generous free daily quotas sufficient for active job searching. You can also run entirely offline using local Ollama at zero cost.
Where is my resume and personal data stored? ▼
All data is stored exclusively on your local machine in %LOCALAPPDATA%\SPravJobAI. This includes your resume, extracted knowledge base, job database, and application history. Zero data is ever transmitted to any external server — not even SPrav's own servers. The application is fully offline for all personal data operations.
Do I need an internet connection to run SPrav™? ▼
An active internet connection is required for job discovery — scanning live ATS feeds (Greenhouse, Lever, Ashby), career pages, and submitting applications. However, for all AI scoring, STAR generation, and ATS rubric evaluation, you can run 100% locally using Local Ollama on your GPU — no internet calls needed for the AI component.
What Python version / OS does it require? ▼
No Python or any other software installation is required. The portable ZIP includes a self-contained Python 3.13 runtime. Just extract and double-click SPravJobAI.exe. Currently Windows-only. macOS and Linux distributions are planned for a future release.
Will SPrav™ apply to jobs automatically without my review? ▼
No — SPrav is designed as a guided dispatch system, not a fully autonomous applier. The engine discovers, scores, and pre-tailors applications, but you always review the cover note, STAR stories, and ATS match before dispatching with 1 click. This keeps your applications high-quality and prevents spam that would damage your reputation with employers.
The job counter seems stuck — is something broken? ▼
Not broken — this is expected behavior during the Playwright Watchlist phase. After fast ATS feeds are ingested (quick count jump), the engine switches to headless browser rendering of custom company career pages. This phase takes 1–3 minutes per cycle as each page loads, executes JavaScript, and is snapshot-diffed. The counter will resume updating when the engine advances to the next ATS ingestion cycle.
